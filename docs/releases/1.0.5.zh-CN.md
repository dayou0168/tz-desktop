# TZ Desktop 1.0.5 源码版

本版本只发布 Windows 客户端源代码，不包含 Windows 二进制文件。LTO 安装包、便携包和调试符号将由高内存 Windows 电脑另行构建和验收。

## 主要更新

- 在“设置 → 隐私与安全”中加入“修改登录密码”。该密码用于 TZ 账号登录，与 Telegram 风格的两步验证密码相互独立。
- 使用服务端约定的 `TZ_LOGIN_PASSWORD_V1` 协议标记提交当前密码和新密码，并对密码长度、重复输入和相同密码进行本地校验。
- 保持简体中文为首次启动默认语言。
- 保持 `tztg.tianze8.cc:2398`、DC2、定制 RSA 公钥及 `tg.tianze8.cc` 分享链接行为不变。
- 统一应用本体、更新器、UWP 清单、构建脚本与源码契约中的版本号为 1.0.5。

## 构建说明

- Windows x64 正式构建必须启用 LTO。
- 本源码版本不替代当前已发布的 1.0.3 LTO 二进制文件。
- 构建完成后仍需验证登录、修改登录密码、断线重连、私聊及群组媒体、分享链接和双客户端互通。
